# The run core

`legate-run.core.mjs` is the verifier the runs repository vendors, built from the Legate site's own source and copied here unchanged, so the grading is made and checked with the same code a reader runs. It compiles a standard to the gate policy, signs and verifies run manifests and regrades, verifies receipt chains, and verifies Sigstore provenance bundles offline against the pinned public-good trust root.
